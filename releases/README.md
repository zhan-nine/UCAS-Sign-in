# 发布安装包

本目录存放面向用户的 Release APK，文件名形如：

```text
qingxin-signin-<version>-release.apk
```

当前推荐版本：`qingxin-signin-1.1.10-release.apk`

## 许可证

分发本目录中的 APK 时，请一并提供对应的许可证与第三方声明（AGPL-3.0 / LGPL-3.0 的要求）：

- [`../LICENSE`](../LICENSE) — GNU AGPL-3.0 全文
- [`../NOTICE`](../NOTICE) — 上游与第三方组件归属声明
- [`../LICENSES/`](../LICENSES) — AGPL-3.0 / LGPL-3.0 完整文本
- 对应源代码：本公开仓库

许可证全文与 `NOTICE` 也已随 APK 打包在 `assets/licenses/` 内。
