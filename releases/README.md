# 发布安装包

本目录存放面向用户的 Release APK，文件名形如：

```text
qingxin-signin-<version>-release.apk
```

当前推荐版本：`qingxin-signin-1.1.13-release.apk`

## 版本要点

### 1.1.13（当前）

- **修复：设置页系统返回键无效**。此前在设置页按系统返回键 / 手势返回会直接退出 App，
  只能点页面左上角的「返回」。现在系统返回（含全面屏手势、三键导航、Android 13+ 预测式返回）
  与页面按钮行为一致，都回到首页。
- **设置页状态可在旋屏 / 进程重建后保留**（`rememberSaveable`），不会突然跳回首页。
- 行为细节：设置页里的弹窗（小部件图文指引、锁定后台步骤、开源许可）仍由系统返回键优先关闭弹窗，
  不会连带退出设置页；退出登录后系统返回恢复为默认的「退出 App」语义。

### 1.1.12

- **后台自动签到**：每节课在「开课前 15 分钟 ~ 上课时刻」之间随机取一个时刻签到。
  随机值**只存在于内存、绝不写入本机**，且**每节课重新随机**，不在设备上留下可识别的固定模式。
- **通知栏常驻提示**：常驻通知显示「自动签到运行中 · 下次自动签到 HH:mm · 课程名」；
  自动签到的**结果通知强制发出**，不受「签到通知」开关影响。
- **保活引导**：设置页新增「后台运行与省电」卡片，可一键弹出「忽略电池优化」授权框、
  跳转厂商自启动页、按 ROM 给出「锁定后台」分步说明，并实时显示各项状态。
- **低耗电模式**（可选）：关闭常驻通知与后台服务，只保留每节课一个闹钟。
- **耗电净下降**：守护进程存活时，小部件的数据兜底闹钟由 10 分钟放宽到 45 分钟
  （单这一项即减少约 100+ 次/天的唤醒）；自动签到改为事件驱动、零轮询。
